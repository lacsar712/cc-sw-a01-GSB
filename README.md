# 光谱波长校准台

校准员先在「灯种牌」建档（写固定称呼并圈可校准），提交校准单时必须圈选一块仍挂牌且可校准的灯。称呼随单落盘即冻结，事后摘牌不影响旧单。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

## 灯种牌规则

- 灯种牌在顶栏单独的「灯种牌」页维护：上格是挂牌灯种（可圈/取消可校准、摘牌），下格是摘牌履历（摘牌人、摘牌时间）。
- 入队必须绑牌：只能选上格里仍挂牌且圈了「可校准」的灯，否则拒收——没圈提示「没圈可校准灯」，摘了牌提示「已摘牌」。
- 固定称呼建档时写定，不可修改；已摘牌的称呼不可复用建档，也不可复挂。
- 称呼随单落盘即冻结：之后摘牌或维护灯种牌，都改不了旧单上的称呼。

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差（旧种子单无绑牌，称呼直接落盘）。
2. 顶栏进「灯种牌」，建档「氦灯甲」并圈可校准；回总览挂甲提交一单，先进待处理，再出结论，单上称呼为「氦灯甲」。
3. 在灯种牌摘掉「氦灯甲」，总览下拉里不再有甲；直接带甲提交被拒收，提示「已摘牌」。
4. 打开第 2 步成功那单，灯种已摘牌，冻结称呼仍显示「氦灯甲」。
5. inspector 登录：只能看灯种牌上格/下格与单子上的冻结称呼，没有建档、圈选、摘牌、提交入口。
