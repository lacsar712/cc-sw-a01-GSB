# 光谱波长校准台

校准员先在「灯种牌」页建档（写固定称呼并圈「可校准」），提交时挂灯种牌入队；只有仍在牌且圈了可校准的灯才能提交。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

称呼随单落盘即冻结：灯种牌事后摘牌不影响旧单上显示的称呼，摘牌履历保留在灯种牌页下格。

```bash
docker compose up --build
```

## 灯种牌规则

- 顶栏进入「灯种牌」页：上格建档（称呼唯一 + 圈可校准）并列在牌灯种，下格为建档 / 摘牌履历。
- 总览提交必须挂灯种牌。服务端在提交瞬间校验：
  - 已摘牌 → 拒收，说明「已摘牌」；
  - 没圈可校准 → 拒收，说明「没圈可校准」；
  - 灯种牌不存在 → 拒收，提示先建档。
- 提交成功后，单上的灯种称呼按当时牌面冻结，摘牌不改旧单。

## 验收

1. calibrator 建档「氦灯甲」并圈可校准，挂它提交 → 进待处理，随后出结论。
2. 摘掉「氦灯甲」后再挂它提交 → 拒收并说明已摘牌；建档时没圈可校准的灯提交 → 拒收并说明没圈。
3. 打开第 1 步成功的单，冻结称呼仍为「氦灯甲」。
4. inspector 只能看牌、履历与冻结称呼，不能建档、摘牌、提交。
5. 种子「氦灯-587」合格、「汞灯-546」超差。
